# 🏭 Aegis Factory

> 생성형 AI와 실시간 데이터를 활용한 스마트팩토리 운영 지원 웹 서비스

Aegis Factory는 제조 현장에서 발생하는 에너지 사용량과 작업자 안전 데이터를 실시간으로 확인하고, AI Agent가 상황을 분석하여 필요한 대응을 지원하는 웹 기반 스마트팩토리 서비스입니다.

Google Cloud AI Agent Challenge에서 개발한 프로젝트로, 서비스 기획부터 프론트엔드 개발, AI Agent 연동 및 전체 서비스 구현까지 직접 진행했습니다.

## 💡 Project Overview

제조 현장에서는 에너지 사용량, 작업자 안전 상태, 설비 정보 등 다양한 데이터가 지속적으로 발생합니다.

Aegis Factory는 이러한 데이터를 사용자가 각각 확인하고 판단해야 하는 과정을 줄이고, AI Agent가 데이터를 분석하여 상황을 판단하고 필요한 정보를 웹 인터페이스를 통해 제공하는 것을 목표로 개발했습니다.

AI가 단순히 질문에 답변하는 서비스가 아니라,

Perceive → Reason → Act → Evaluate

구조를 기반으로 현장 데이터를 인식하고 상황을 판단한 뒤 필요한 행동을 수행하고 결과를 다시 평가할 수 있도록 설계했습니다.

## ✨ Key Features

### 1. 실시간 Factory Dashboard

공장 내 4개 구역의 상태를 하나의 대시보드에서 확인할 수 있도록 구현했습니다.

- 구역별 센서 데이터 표시
- 에너지 사용 상태 실시간 확인
- 안전 상태 모니터링
- 주요 지표 시각화
- 상태 변화에 따른 UI 업데이트

여러 데이터를 단순히 나열하기보다 사용자가 현재 공장의 상태를 빠르게 파악할 수 있도록 정보의 중요도에 따라 화면을 구성했습니다.

---

### 2. AI 기반 에너지 관리

공장 내부의 에너지 사용 데이터를 AI Agent가 분석하고 운영자가 필요한 정보를 확인할 수 있도록 구현했습니다.

- 구역별 에너지 사용량 분석
- 에너지 절감 방안 제안
- 센서 데이터 기반 운영 상태 분석
- 절감 결과 및 주요 지표 시각화

AI의 분석 결과가 단순 텍스트 응답으로 끝나지 않고 실제 웹 서비스의 데이터 및 UI와 연결되도록 구성했습니다.

---

### 3. 작업자 안전 모니터링

현장 데이터를 기반으로 작업자의 안전 상태를 판단하고 위험 수준에 따라 대응할 수 있도록 구현했습니다.

위험도를 다음과 같이 단계화했습니다.

Level 1 → Level 2 → Level 3

- 안전모 착용 여부 확인
- 작업 구역 과밀 상태 감지
- 위험 수준 분류
- 위험 상황 발생 시 대응 정보 제공
- 현장 방송 기능과 연계

객체 탐지 모델의 성능은 **mAP@0.5 기준 92.3%**를 기록했으며 약 1,200장의 데이터를 활용했습니다.

---

### 4. AI Agent

Aegis Factory의 AI Agent는 다음 구조를 기반으로 동작합니다.

text Perceive    ↓ Reason    ↓ Act    ↓ Evaluate 

Perceive

센서 데이터와 공장 상태 정보를 수집합니다.

Reason

수집된 데이터를 기반으로 현재 상황과 위험 요소를 분석합니다.

Act

분석 결과에 따라 에너지 절감 방안 제안, 안전 경고, 운영 정보 제공 등의 작업을 수행합니다.

Evaluate

수행 결과와 변경된 데이터를 다시 확인하여 이후 판단에 반영합니다.

이를 통해 단순한 LLM API 호출이 아닌, 상태를 인식하고 판단하여 행동하는 Agent 구조를 구현하고자 했습니다.

---

### 5. Shift Report 자동 생성

공장 운영 데이터를 기반으로 Shift Report를 자동 생성하도록 구현했습니다.

- 에너지 사용 현황
- 안전 이벤트
- 주요 운영 상태
- 조치 결과

등을 종합하여 관리자가 현장의 주요 내용을 빠르게 확인할 수 있도록 구성했습니다.

반복적인 보고서 작성 업무를 줄이고 운영자가 중요한 의사결정에 집중할 수 있도록 하는 것을 목표로 했습니다.

---

### 6. 자연어 기반 데이터 조회

사용자가 복잡한 데이터 조회 방법을 알지 못해도 자연어를 통해 필요한 정보를 확인할 수 있도록 구현했습니다.

예를 들어,

text 오늘 에너지 사용량이 가장 높은 구역은 어디야? 

text 현재 안전 위험이 발생한 구역을 알려줘. 

와 같은 질문을 통해 공장 데이터를 조회하고 결과를 확인할 수 있도록 설계했습니다.

## 🖥️ Frontend

Aegis Factory의 프론트엔드는 React + Vite를 기반으로 구현했습니다.

AI 기능을 단순히 API 형태로 제공하는 것이 아니라 사용자가 AI의 분석 과정과 결과를 직관적으로 확인할 수 있는 웹 인터페이스를 만드는 데 집중했습니다.

### 주요 구현 내용

- 컴포넌트 기반 UI 구성
- 공장 운영 Dashboard 구현
- 센서 및 상태 데이터 시각화
- 사용자 인터랙션에 따른 동적 UI 업데이트
- AI Agent 결과와 UI 연결
- 에너지 및 안전 상태 실시간 표현
- 다양한 운영 정보를 하나의 화면에서 확인할 수 있는 정보 구조 설계

기능별 UI를 컴포넌트 단위로 분리하여 유지보수성과 재사용성을 고려했으며, 상태 변화에 따라 필요한 정보가 즉시 화면에 반영되도록 구성했습니다.
